# 09 — Official Valve drivers

Source: [Steam Hardware — Windows Resources](https://help.steampowered.com/en/faqs/view/6121-ECCD-D643-BAA8).

Download the correct **LCD** or **OLED** set. Extract each ZIP to its own folder.
Install **from USB** (Wi‑Fi may be missing).

Typical order (always follow Valve’s FAQ for that day):

1. **APU / GPU**  
2. microSD  
3. Bluetooth  
4. Wi‑Fi  
5. Audio (multiple folders; OLED may add an extra codec)

Reboot. Verify audio, Wi‑Fi, BT.

# 10 — rEFInd on Windows (official bootnext)

Do **not** use old MediaFire “Dual Boot Fix” zips.

1. Download the **Windows app** from [SteamDeck_rEFInd Releases](https://github.com/jlobue10/SteamDeck_rEFInd/releases).  
2. Install and enable **bootnext / Sysd** equivalent (scheduled task keeping rEFInd first in EFI order).  
3. Optional: `Win+R` → `msconfig` → Boot → **No GUI boot** → Apply.

Shut down.

Next: [Finalize dual-boot](11-finalize-dualboot.md).

# 04 — Prepare SteamOS

**Gaming Mode:** Steam → Settings → System → check for updates → reboot.

**Desktop Mode:** System Settings → User → set a **sudo password** (needed by rEFInd).

Do **not** partition from normal Desktop — the internal drive is often locked. Use Recovery later.

# 01 — Overview

Rekorddeck takes a stock **Steam Deck (SteamOS)** to a **dual-boot** with Windows
for DJ work (**rekordbox 6** + ASIO). This guide assumes you prepare USB/SD media
on a **Linux PC**.

## Audience

**Primary:** Windows **10 Pro** or **11 Pro** (legitimate license).  
**Advanced:** LTSC 2021 if you already manage that channel.

See [status](00-status.md). Using a Windows PC for media? → [Windows guide](../../from-windows/en/01-overview.md).

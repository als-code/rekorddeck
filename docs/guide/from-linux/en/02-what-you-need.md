# 02 — What you need

## Hardware

- Steam Deck (LCD or OLED), ideally **≥256 GB** internal  
- Windows partition: **≥64 GB**, recommended **80 GB+**  
- **2** USB sticks or microSDs ≥8 GB (or one Ventoy stick holding both ISOs)  
- USB-C hub + keyboard  
- A **Linux PC** to write images  

## Software / accounts

- Legitimate **Windows 10 Pro or 11 Pro** license  
- Windows ISO from Microsoft / your legal channel  
- [SteamOS recovery image](https://help.steampowered.com/en/faqs/view/65B4-2AA3-5F37-4227)  
- [Steam Deck Windows drivers](https://help.steampowered.com/en/faqs/view/6121-ECCD-D643-BAA8)  
- [Ventoy](https://www.ventoy.net/) and/or `dd` / woeusb-ng / balenaEtcher  
- [SteamDeck_rEFInd](https://github.com/jlobue10/SteamDeck_rEFInd)  

## Do not use

- Third-party activators (MAS, etc.)  
- Old MediaFire “Dual Boot Fix” zips — use **official rEFInd bootnext**

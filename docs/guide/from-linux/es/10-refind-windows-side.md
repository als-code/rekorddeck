# 10 — rEFInd lado Windows (bootnext oficial)

**No** uses zips “Dual Boot Fix” de MediaFire de tutoriales antiguos.

1. Descarga la **app Windows** de [SteamDeck_rEFInd Releases](https://github.com/jlobue10/SteamDeck_rEFInd/releases).  
2. Instálala y activa el equivalente a **bootnext / Sysd** (tarea programada que pone rEFInd primero en la lista EFI al iniciar Windows).  
3. Opcional anti-glitch: `Win+R` → `msconfig` → Arranque → **Sin arranque GUI** → Aplicar.

Apaga el Deck.

Siguiente: [Finalizar dual-boot](11-finalize-dualboot.md).

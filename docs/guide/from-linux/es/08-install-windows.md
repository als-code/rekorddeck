# 08 — Instalar Windows (10/11 Pro)

1. **Vol− + Power** → USB Windows.  
2. Instalar Windows → acepta licencia.  
3. Clave: la tuya, o “no tengo clave” si tu canal permite activar después (**activa legalmente** antes de un bolo).  
4. Elige **Windows 10/11 Pro**.  
5. Tipo: **solo Windows** / custom (no upgrades).  
6. En la lista de particiones, elige la **NTFS** que creaste en Recovery → Siguiente.  
   **No** borres particiones EFI/SteamOS.  
7. Tras reinicios: si el OOBE exige Wi‑Fi y no tienes drivers aún, usa bypass documentado de Microsoft para “no tengo Internet” (p. ej. `Shift+F10` + flujo OOBE\bypassnro en builds que aún lo permiten) **solo** para completar setup local.  
8. En escritorio: Orientación de pantalla → **Horizontal**.

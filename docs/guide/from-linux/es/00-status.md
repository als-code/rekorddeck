# 00 — Estado y huecos

**Esta guía:** preparas los medios en un **PC Linux**, luego dual-boot en el Deck.

**Ruta recomendada:** Windows 10/11 Pro + debloat DJ. Pre-alpha.

## Recomendado vs avanzado

| Ruta | Rol |
|------|-----|
| **Windows 10/11 Pro** | **Principal** |
| **LTSC 2021** | **Solo avanzados** |

## Orden canónico

1. Medios Recovery + Windows en **PC Linux** (Recovery = stick dedicado `dd`/Etcher; Windows = Ventoy / woeusb OK)  
2. Update SteamOS + password → rEFInd → partición Recovery → Windows  
3. Drivers → bootnext → capa DJ

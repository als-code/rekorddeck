# 00 — Estado y huecos

**Esta guía:** preparas los medios en un **PC Windows**, luego haces dual-boot en el Deck.

**Ruta recomendada:** Windows 10/11 Pro + debloat DJ. Pre-alpha.

## Recomendado vs avanzado

| Ruta | Rol |
|------|-----|
| **Windows 10/11 Pro** | **Principal** |
| **LTSC 2021** | **Solo avanzados** |

## Orden canónico

1. USBs Recovery + Windows en **PC Windows** (Rufus)  
2. Update SteamOS + password  
3. rEFInd → partición desde **Recovery** → instalar Windows  
4. Drivers Valve → bootnext oficial → cerrar dual-boot  
5. Capa DJ

# 09 — Drivers oficiales Valve

Fuente: [Recursos Windows Steam Deck](https://help.steampowered.com/es/faqs/view/6121-ECCD-D643-BAA8)  
(EN: [same FAQ](https://help.steampowered.com/en/faqs/view/6121-ECCD-D643-BAA8)).

Descarga el paquete **LCD** u **OLED** correcto. Extrae cada ZIP a su carpeta.
Instala **desde el USB** (Wi‑Fi puede no existir aún).

Orden típico (sigue siempre la FAQ Valve del día):

1. **APU / GPU** (`setup`)  
2. Lector microSD  
3. Bluetooth  
4. Wi‑Fi  
5. Audio (varios INF / carpetas; OLED puede traer codec extra)

Reinicia. Verifica sonido, Wi‑Fi, BT.

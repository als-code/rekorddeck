# 16 — Recuperación y updates

- Tras update SteamOS: Desktop → rEFInd → Create/Install Config + Sysd On.  
- Si Windows se queda con el EFI: boot manual a SteamOS y reinstala config / bootnext.  
- Reloj dual-boot: en Windows admin, `RealTimeIsUniversal=1` (ver guías UTC).  
- Antes de un bolo: pausar Windows Update; no desactives el servicio a lo bruto.

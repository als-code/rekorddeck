# 08 — Install Windows (10/11 Pro)

1. **Vol− + Power** → Windows USB.  
2. Install Windows → accept license.  
3. Product key: yours, or skip if your channel allows later activation (**activate legally** before gigs).  
4. Select **Windows 10/11 Pro**.  
5. **Custom** / Windows only.  
6. Select the **NTFS** partition from Recovery → Next. Do **not** wipe EFI/SteamOS.  
7. If OOBE demands Wi‑Fi before drivers: use Microsoft’s documented “I don’t have internet” bypass for your build (e.g. Shift+F10 + OOBE\bypassnro where still applicable) only to finish local setup.  
8. Desktop → Display → **Landscape**.

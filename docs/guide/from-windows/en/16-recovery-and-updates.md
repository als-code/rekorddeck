# 16 — Recovery and updates

- After SteamOS updates: rEFInd → Create/Install Config + Sysd On.  
- If Windows stole EFI: manual SteamOS boot, then reinstall config / bootnext.  
- Dual-boot clock: set Windows `RealTimeIsUniversal=1` (UTC).  
- Before gigs: pause Windows Update; do not nuke the Update service.

# 11 — Finalize dual-boot

1. Boot SteamOS manually if needed (**Vol+ + Power** / boot-from-file → steamos EFI).  
2. Desktop → **SteamDeck_rEFInd** → **Create Config** → **Install Config**.  
3. Reboot into the SteamOS | Windows menu.

If the menu vanishes after a SteamOS update: repeat Create/Install + Sysd On.  
See [Recovery](16-recovery-and-updates.md).

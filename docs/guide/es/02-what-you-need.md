# 02 — Qué necesitas

## Hardware

- Steam Deck (LCD u OLED), ideal **≥256 GB** interno  
- Partición Windows: **mín. 64 GB**, recomendado **80 GB+** (biblioteca fuera de `C:`)  
- **2** pendrives o microSD ≥8 GB (uno Recovery SteamOS, uno Windows)  
- Hub USB-C + teclado (y ratón si puedes)  
- PC o portátil con **Windows o Linux** para grabar las imágenes  

## Software / cuentas

- Licencia **legítima** de Windows 10 Pro o 11 Pro (LTSC solo si ya eres avanzado)  
- ISO Windows desde Microsoft / tu canal legal  
- Imagen de [recuperación SteamOS](https://help.steampowered.com/es/faqs/view/1B71-EDF2-EB8D-2BA0) (o FAQ Recovery actual de Valve)  
- Drivers [Windows en Deck](https://help.steampowered.com/es/faqs/view/6121-ECCD-D643-BAA8) (descárgalos al USB)  
- [SteamDeck_rEFInd](https://github.com/jlobue10/SteamDeck_rEFInd)  

## No uses

- Activadores de terceros (MAS, etc.)  
- “Dual Boot Fix” de MediaFire de vídeos antiguos — usa el **bootnext oficial** de rEFInd

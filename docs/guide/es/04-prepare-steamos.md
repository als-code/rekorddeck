# 04 — Preparar SteamOS

En **Gaming Mode**:

1. Steam → Ajustes → Sistema → buscar actualizaciones e instalar.  
2. Reinicia.

En **Desktop Mode**:

1. Ajustes del sistema → Usuario → **establecer contraseña sudo**.  
2. Anótala: rEFInd la pedirá.

No particiones aún desde Desktop: el disco interno suele estar **bloqueado**; eso se hace desde Recovery.

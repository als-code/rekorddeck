# 01 — Overview

Rekorddeck te lleva de un **Steam Deck (SteamOS)** de fábrica a un **dual-boot**
con Windows para DJ (**rekordbox 6** + ASIO), dejando SteamOS para jugar.

## Para quién

**Ruta principal:** Windows **10 Pro** o **11 Pro** (licencia legítima).  
**Avanzado:** LTSC 2021 si ya sabes gestionar ese canal.

Ver [estado y huecos](00-status.md).

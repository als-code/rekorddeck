# 11 — Finalizar dual-boot

1. Enciende con **Vol+ + Power** (o Vol− según BIOS) y arranca SteamOS a mano si hace falta  
   (Boot from file → `ESP` → `efi` → `steamos` → `steamcl.efi` — rutas pueden variar).  
2. Desktop Mode → abre **SteamDeck_rEFInd**.  
3. **Create Config** → **Install Config** (sudo).  
4. Reinicia: deberías ver el menú SteamOS | Windows.

Si el menú desaparece tras un update de SteamOS: vuelve aquí y repite Create/Install + Sysd On.
